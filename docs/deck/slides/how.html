HOW IT WORKS

Each tap asks the most useful question.

  1. We simulate 2,500 possible students from a small Bayesian model: campus → commute mode → parking, budget, value of time.
  2. Each answer re-weights them (likelihood weighting). The confidence meter = P(your true best is in our top 3).
  3. Next question = highest expected information gain. Under 0.03 bits? Never asked.
  4. Stop at 95% confidence or 5 taps.
